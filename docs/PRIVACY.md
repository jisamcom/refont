# Refont 개인정보처리방침

**시행일: 2026년 6월 5일**

Refont(이하 "본 확장프로그램")는 웹페이지의 본문 폰트를 사용자가 지정한 폰트로 바꿔 주는 브라우저 확장프로그램입니다. 본 확장프로그램은 **어떠한 개인정보도 수집·저장·전송하지 않습니다.**

## 한눈에 보기

- 분석(애널리틱스)·추적·텔레메트리가 **전혀 없습니다.**
- 개발자가 운영하는 서버가 **없습니다.** 어디로도 데이터가 전송되지 않습니다.
- 광고·광고 ID·핑거프린팅이 **없습니다.**
- 회원가입·로그인·계정이 **없습니다.**

## 본 확장프로그램이 저장하는 것

본 확장프로그램은 사용자의 **설정값만**(선택한 폰트, 크기·자간·줄간격 등 조정값, 제외 사이트 목록, 보호 폰트 목록, 최근 사용 폰트) 브라우저의 로컬 저장소(`storage.local`)에 저장합니다.

- 이 데이터는 **사용자 기기에만** 저장되며 기기 밖으로 나가지 않습니다.
- 개발자를 포함한 누구에게도 전송되지 않습니다.
- 확장프로그램을 삭제하면 이 데이터도 함께 삭제됩니다.

## 네트워크 요청에 대하여

본 확장프로그램이 외부로 보내는 네트워크 요청은 **단 한 가지** 경우뿐입니다.

> 사용자가 "웹폰트 URL"을 **직접 입력**해 폰트를 지정한 경우, 그 폰트 파일을 받아오기 위해 **사용자가 입력한 바로 그 주소**로 요청을 보냅니다.

- 이 요청은 사용자가 선택한 폰트 제공처(예: Google Fonts, 직접 지정한 CDN 등)로 **직접** 전송됩니다.
- 개발자의 서버를 거치지 않으며, 개발자는 이 요청에 대한 어떤 정보도 받지 않습니다.
- 받아온 폰트는 현재 페이지에 적용하기 위해서만 사용됩니다.
- 폰트 URL을 입력하지 않으면(시스템에 설치된 폰트만 사용하면) 본 확장프로그램은 어떤 네트워크 요청도 보내지 않습니다.

해당 폰트 제공처가 자체적으로 어떤 정보를 처리하는지는 그 제공처의 개인정보처리방침을 따릅니다.

## 권한을 사용하는 이유

- **storage** — 위에서 설명한 설정값을 기기에 저장하기 위해.
- **scripting** — 페이지에 폰트 교체용 CSS를 주입하기 위해.
- **tabs** — 현재 탭의 주소를 확인해 "이 사이트 제외"·툴바 배지를 처리하기 위해.
- **host 권한(`<all_urls>`)** — 사용자가 방문하는 어떤 사이트에서도 폰트를 교체할 수 있도록. 페이지 내용을 읽어 외부로 보내는 용도가 **아닙니다.**

## 어린이 개인정보

본 확장프로그램은 어떤 사용자로부터도 개인정보를 수집하지 않으며, 여기에는 어린이도 포함됩니다.

## 방침 변경

본 방침이 변경되면 이 문서와 시행일을 갱신합니다. 데이터를 수집하지 않는다는 원칙은 그대로 유지하는 것을 목표로 합니다.
