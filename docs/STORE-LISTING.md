## Chrome Web Store

### 요약 (Summary, 132자 이내)

```
웹페이지 본문 글꼴을 원하는 폰트로 바꿉니다. 아이콘·수식·악보·바코드·이모지 같은 '기능성 폰트'는 자동 감지해 보호하므로 화면이 깨지지 않습니다.

### 카테고리

- 1순위: **접근성(Accessibility)** — 가독성 향상 목적
- 대안: 도구/기능(Tools / Functionality & UI)

### 상세 설명 (Description)

```
Refont는 어떤 웹페이지든 본문 글꼴을 당신이 고른 폰트로 바꿔 줍니다.
딱 한 가지에 집중합니다 — 읽기 좋은 글꼴로 웹을 보는 것. 그러면서도
"폰트가 곧 기능"인 글꼴은 건드리지 않아 화면이 깨지지 않습니다.

■ 기능성 폰트 자동 보호
아이콘 폰트(Font Awesome, Material Icons/Symbols, Bootstrap Icons 등),
수식(KaTeX·MathJax·STIX), 악보(SMuFL·Bravura), 바코드, 딩벳(Wingdings),
이모지, 그리고 글리프 매핑을 뒤섞는 안티스크래핑 폰트까지 — 폰트 이름,
사용자 영역(PUA) 문자, 흔한 아이콘 클래스 힌트를 종합해 자동으로 감지하고
보호합니다. 본문만 바뀌고 아이콘과 수식은 그대로 남습니다.

■ 원하는 폰트로
· 컴퓨터에 설치된 폰트 중에서 선택 (한글 폰트는 한글 이름으로 표시)
· 웹폰트도 사용 가능 — Google Fonts CSS 링크 또는 .woff2/.ttf/.otf 직접 URL
  (직접 URL 방식은 백그라운드에서 받아 data: 폰트로 주입하므로 CSP가
  엄격한 사이트에서도 동작)
· 코드/고정폭 영역에만 별도 폰트 지정 가능

■ 세밀한 조정
크기 배율, 최소 글자 크기, 굵기(제목 굵기는 유지 옵션), 줄간격, 자간,
그리고 가변 폰트 축(opsz·wdth 등)까지 직접 조절. 편집하는 동안 현재 탭에
실시간으로 미리 적용되고, "기본값으로 초기화" 한 번이면 처음 상태로.

■ 사이트별 제어
· 특정 사이트 제외(블록리스트)
· 특정 요소만 제외 (CSS 선택자) — 예: 가격표·표 등은 원래 폰트 유지
· 단축키 Alt+Shift+F 로 현재 사이트 켜고 끄기
· 페이지에서 실제로 쓰이는 폰트 목록을 보여 주고, '기능성/본문'으로
  분류해 보호 목록에 한 번에 추가

■ 사생활 보호
계정도, 서버도, 추적도 없습니다. 설정은 당신 기기에만 저장됩니다.
유일한 네트워크 요청은 당신이 직접 입력한 폰트 URL에서 폰트를 받아오는
것뿐입니다. 자세한 내용은 개인정보처리방침을 참고하세요.

Chrome과 Firefox에서 동작합니다. Manifest V3.
```

### 단일 목적 설명 (Single purpose)

```
웹페이지 텍스트의 글꼴을 사용자가 지정한 폰트로 교체합니다. 단,
아이콘·수식·바코드·이모지처럼 폰트 자체가 기능인 글꼴은 그대로 유지합니다.
```

### 권한 사용 사유 (Permission justifications)

- **storage**
  ```
  사용자가 선택한 폰트와 조정값(크기·자간 등), 제외 사이트 목록 등 설정을
  기기에 저장하기 위해 사용합니다. 저장된 데이터는 외부로 전송되지 않습니다.
  ```
- **scripting**
  ```
  페이지 텍스트의 글꼴을 바꾸기 위한 CSS를 현재 페이지에 주입하는 데
  사용합니다.
  ```
- **tabs**
  ```
  현재 탭의 주소(호스트)를 확인해 '이 사이트 제외' 기능과 툴바 배지를
  처리하기 위해 사용합니다.
  ```
- **host 권한 `<all_urls>`**
  ```
  사용자가 방문하는 어떤 사이트에서든 글꼴을 교체하려면 모든 사이트에 대한
  접근이 필요합니다. 페이지 내용을 읽어 외부로 보내는 용도가 아니며, 글꼴
  교체용 CSS 주입에만 사용합니다.
  ```

### 개인정보 보호 관행 (Privacy practices 탭)

- 데이터 수집 항목: **전부 "수집하지 않음"으로 체크**
- 아래 3개 항목 인증(체크):
  - 사용자 데이터를 승인된 용도와 무관하게 제3자에게 판매·양도하지 않습니다.
  - 단일 목적과 무관한 용도로 사용·전송하지 않습니다.
  - 신용도 판단이나 대출 목적으로 사용·전송하지 않습니다.

```

## 참고: 이름을 더 설명적으로 쓰고 싶다면

스토어 표시 이름은 매니페스트의 `name`을 따릅니다. 현재는 `Refont`입니다.
더 검색 친화적으로 바꾸고 싶다면 양쪽 매니페스트(`public/manifest.chrome.json`,
`public/manifest.firefox.json`)의 `name`을 예: `"Refont — 웹폰트 교체 (기능성 폰트 보호)"`
처럼 바꾼 뒤 다시 빌드/패키징하면 됩니다. (현재는 짧은 `Refont` 유지를 권장)
